## 实现说明

- **曲线参数**：SM2 椭圆曲线（sm2p256v1）。
- **哈希**：SM3（含 HMAC），并用于 RFC 6979 风格的确定性 `k`。
- **签名/验签**：严格按规范：
  - `e = SM3( ZA(ID, P) || M )`
  - `r = (e + x1) mod n`
  - `s = (1 + d)^(-1) * (k - r d) mod n`
  - 验证：`t = r + s`，检查 `(e + x1') mod n == r`，其中 `X1' = sG + tP`
- **演示脚本**：`sm2_all_pocs.py` 一键运行所有 PoC，并打印验证通过/失败。

> 说明：此实现以可读性和教学为主，未做侧信道与时序攻击的常数时间防护；椭圆曲线运算使用仿射坐标与扩展欧几里得求逆，便于理解。

## PoC 列表与推导

记号：曲线 `E: y^2 = x^3 + a x + b (mod p)`；基点 `G`，阶 `n`；私钥 `d`，公钥 `P=dG`；`ZA=SM3(ENTL||ID||a||b||Gx||Gy||Px||Py)`；`e=SM3(ZA||M)`。

### 1. 泄露 `k` ⇒ 恢复私钥 `d`

SM2： `s = (1 + d)^(-1) * (k - r d)`  
乘 `(1 + d)` 并整理：  
`d ≡ (k - s) * (s + r)^(-1)  (mod n)`  

**实现**：`poc_leak_k(r, s, k)`。

---

### 2. 同一私钥重复使用相同 `k`

两式：  
`s1 = (1 + d)^(-1) * (k - r1 d)`  
`s2 = (1 + d)^(-1) * (k - r2 d)`  
相减并化简（幻灯片给出的闭式）：  
`d ≡ (s2 - s1) * (s1 - s2 + r1 - r2)^(-1)  (mod n)`  

**实现**：`poc_reuse_k_same_user(r1, s1, r2, s2)`。

---

### 3. 不同用户重用同一 `k`

受害者签名：`s = (1 + d)^(-1) * (k - r d)`  
攻击者已知 `k`，直接代回：  
`d ≡ (k - s) * (s + r)^(-1)  (mod n)`  

**实现**：`poc_reuse_k_two_users(k, r, s)`。

---

### 4. **ECDSA 与 SM2 共用相同 `k`**（重点）

ECDSA：`s_E = k^(-1) * (e_E + d r_E)`  
SM2：`s_S = (1 + d)^(-1) * (k - r_S d)`  
由 ECDSA：`k = (e_E + d r_E) * s_E^(-1)`  
由 SM2：`k = s_S (1 + d) + r_S d`  
联立整理：  
`d ≡ (s_E s_S - e_E) * (r_E - s_E s_S - s_E r_S)^(-1)  (mod n)`  

**实现**：`poc_cross_scheme_recover_d(rE, sE, eE, rS, sS)`。

---

### 5. 伪造“中本聪签名”（错误验证器）

正确验证：`e=SM3(ZA||M)`；`t=r+s`；`X1=sG+tP`；检查 `(e+X1.x) mod n == r`。  
错误实现若**不重算 e**，而**盲信外部 e_supplied**，攻击者可令：  
- 随机 `s, t`，计算 `X1=sG+tP`  
- 设置 `r=(t-s) mod n`，`e_supplied = (r - X1.x) mod n`  
- 错误验证器将通过；正确实现会拒绝。  

**实现**：`buggy_verify_no_message` 与 `forge_signature_against_buggy_verifier`。

## 防御建议
1. **绝不重用 `k`**（RFC 6979 或高质量 CSPRNG）。  
2. **跨算法禁止共享 `k`**。  
3. **验证端必须重算 `e`**，绑定消息与公钥。  
4. **严格输入校验**：`r,s ∈ [1,n-1]`，公钥在曲线上且非无穷远点。  
5. **实现侧信道防护**：常数时间运算、统一时间的输入检查等。
