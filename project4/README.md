# Project4 - SM3 实现

## 项目概述
这个项目包含了多种 SM3 加密哈希算法的实现，包括基础实现、并行实现以及基准测试工具。SM3 是中国国家标准的加密哈希函数，广泛应用于各种安全场景中。

## 文件结构
- `sm3_base.c`: SM3 的基础实现。
- `sm3_parallel.c`: SM3 的并行实现，优化了多核处理器的性能。
- `sm3_benchmark.c`: 基准测试工具，用于评估不同实现的性能。
- `sm3.h`: SM3 的头文件，定义了接口和宏。
- `CMakeLists.txt`: CMake 构建配置文件。
- `build/`: 构建生成目录，包含编译结果如 `libsm3_base.a`、`libsm3_parallel.a` 和测试程序。

## 功能
- **基础实现**: 提供标准的 SM3 哈希计算功能。
- **并行实现**: 利用多线程技术，提升多核 CPU 的计算效率。
- **基准测试**: 提供性能测试工具，方便比较不同实现的性能。

## 依赖
- CMake 3.30.3 或更高版本
- GCC 7.5 或更高版本 / Clang 9.0 或更高版本
- make 工具

## 编译与运行
1. 创建构建目录并运行 CMake：
   ```bash
   mkdir build
   cd build
   cmake ..
   make
   ```
2. 运行测试程序：
   ```bash
   ./sm3_benchmark
   ```
   这将执行基准测试，显示不同实现的性能指标。

## 测试
- **基准测试**: 通过 `sm3_benchmark` 比较基础实现和并行实现的性能差异。
- **结果分析**: 并行实现在多核 CPU 上表现更优，适用于高并发场景。

## 优化
- **并行计算**: 利用多线程技术，充分发挥多核 CPU 的计算能力。
- **内存优化**: 优化了内存访问模式，减少了缓存失效，提升了性能。
- **SIMD 指令**: 使用 SIMD 指令加速计算，进一步提高吞吐量。

## 原理
SM3 算法基于 Merke-Damgård 结构，主要包括消息扩展、主循环和最终压缩三个步骤。以下是其核心原理和数学公式：

### 消息扩展
消息被分割为 16 字 (32 位) 的块，并进行扩展，使其长度满足特定要求。

### 主循环
主循环包括以下步骤：
1. 消息扩展。
2. 初始化 8 个 32 位寄存器。
3. 进行 64 轮压缩，使用非线性变换和线性变换。

### 最终压缩
将主循环的输出进行最终压缩，生成 256 位的哈希值。

### 数学公式
SM3 的核心压缩函数包括以下步骤：

1. **布尔函数**：
   - $ f_j(X, Y, Z) $：根据轮次 $ j $ 的不同，使用不同的布尔函数。

2. **轮次函数**：
   - $ g_j(X, Y, Z) = (X \oplus Y \oplus Z) \oplus W_j $

3. **压缩函数**：
   - $ H = H \oplus g_j(A, B, C) $
   - $ B = B \oplus g_j(A, B, C) $
   - $ A = A \oplus f_j(A, B, C) \oplus g_j(A, B, C) $

4. **消息扩展**：
   - $ W_j = M_j \oplus K_j $

### 整体流程
SM3 的哈希计算过程可以表示为：
$ \text{Hash} = \text{SM3}(\text{Message}) $
其中，$\text{Message}$ 是输入消息，$\text{Hash}$ 是输出的 256 位哈希值。
这个项目为 SM3 算法提供了高效且可扩展的实现，适用于需要高性能哈希计算的应用场景。
